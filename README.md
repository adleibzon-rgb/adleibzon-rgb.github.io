# PCA

Сайт закрытого клуба PCA: рабочий стол в стилях Luna · 2001 и Aqua · 2009 с каталогом проектов, документами, играми и ИИ-ассистентом.

- Для клиентов: [как пользоваться ассистентом](docs/CLIENT_GUIDE.md), [описание платформы](docs/PLATFORM.md).
- Вход для подписчиков — кнопка «Войти через Telegram» на сайте.

Сайт статический, публикуется через GitHub Pages из ветки `main`. Серверная часть (API, вход через Telegram, ассистент) живёт в отдельном приватном репозитории; адрес сервера задаётся в `index.html`:

```html
<meta name="pca-api" content="https://api.example.com">
```
